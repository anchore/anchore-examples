# stig-auto-scan

> Generated by [Claude Code](https://claude.com/claude-code).

Runs the right STIG profile against an image without the pipeline needing to
know what OS the image is built on.

1. `anchorectl image add IMAGE --wait`: analyzes the image in Anchore Enterprise
2. `anchorectl image get IMAGE -o json`: reads `.imageContent.metadata.distro` / `.distroVersion`
3. Maps the OS to one of the profiles bundled with anchorectl (`anchorectl stig write-profiles`)
4. `anchorectl stig docker image execute repo:tag@digest -p <profile> -i <profile-inputs.yaml>`

| Detected OS             | Profile      |
|-------------------------|--------------|
| rhel 8.x (incl. UBI 8)  | `rhel8`      |
| rhel 9.x (incl. UBI 9)  | `rhel9`      |
| ubuntu 22.04            | `ubuntu2204` |
| ubuntu 24.04            | `ubuntu2404` |
| wolfi / chainguard      | `chainguard` |

Use `--allow-rhel-clones` to also map centos/rocky/almalinux/ol to the RHEL profiles.

## Requirements

- `anchorectl` v6+ configured for your Anchore Enterprise (`ANCHORECTL_URL`,
  `ANCHORECTL_USERNAME`, `ANCHORECTL_PASSWORD` or a config file)
- `jq`
- A Docker daemon (or Podman, see [../podman-stigs](../podman-stigs)). The STIG
  evaluation runs inside a container created from the image.

## Usage

```bash
./stig-auto-scan.sh registry.example.com/app/myimage:1.2.3

# CI: keep results as an artifact, fail the job if more than 25 controls fail
./stig-auto-scan.sh -o stig-results --fail-threshold 25 registry.example.com/app/myimage:1.2.3

# see what OS/profile would be picked without running anything
./stig-auto-scan.sh --skip-add --dry-run registry.example.com/app/myimage:1.2.3

# custom inputs/waivers, use pinned profiles instead of the bundled ones
./stig-auto-scan.sh -d ./my-profiles -i my-inputs.yaml -w waivers.yaml IMAGE

# pass extra flags through to `anchorectl stig docker image execute`
./stig-auto-scan.sh IMAGE -- --stig-tools-image docker.io/library/busybox:musl
```

Run `./stig-auto-scan.sh --help` for every option.

Exit codes: `0` success, `1` error, `2` no STIG profile for the detected OS
(`--skip-unsupported` makes this `0`), `3` failed controls exceeded `--fail-threshold`.

## GitLab CI example

```yaml
stig_scan:
  stage: test
  image: docker:latest
  services: [docker:dind]
  variables:
    ANCHORECTL_URL: https://anchore.example.com
    # ANCHORECTL_USERNAME / ANCHORECTL_PASSWORD as masked CI variables
  before_script:
    - apk add --no-cache bash curl jq
    - curl -sSfL -u "$ANCHORECTL_USERNAME:$ANCHORECTL_PASSWORD" "$ANCHORECTL_URL/v2/system/anchorectl?operating_system=linux&architecture=amd64" -H "accept: */*" | tar -zx anchorectl
    - mv anchorectl /usr/local/bin/
  script:
    - ./tools/stig-auto-scan/stig-auto-scan.sh -o stig-results --fail-threshold 25 "$CI_REGISTRY_IMAGE:$CI_COMMIT_SHORT_SHA"
  artifacts:
    when: always
    paths: [stig-results/]
```
